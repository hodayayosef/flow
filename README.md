# Flow

אפליקציה לניהול כסף חודשי שרצה על המחשב שלך, עם כניסה בשם משתמש וסיסמה. לכל משתמש יש חשבון פרטי משלו.

## מה צריך

Python 3.9 ומעלה. אפשר להוריד מ-python.org.
ב-Windows, בזמן ההתקנה מסמנים את התיבה **"Add Python to PATH"**.

## הפעלה

**Windows:** לחיצה כפולה על `run.bat`.

**Mac / Linux:** פותחים Terminal בתיקייה ומריצים:
```
./run.sh
```

בפעם הראשונה ההפעלה מתקינה את מה שצריך (לוקח כדקה). אחר כך הדפדפן נפתח לבד בכתובת
http://127.0.0.1:5000

נרשמים עם שם משתמש וסיסמה, ומתחילים.
כדי לעצור את האפליקציה סוגרים את החלון השחור או לוחצים Ctrl+C.

## להתקין כאפליקציה במחשב

ב-Chrome או Edge, כשהאתר פתוח, יש בשורת הכתובת אייקון "התקנה".
אחרי ההתקנה האפליקציה נפתחת בחלון משלה ויש לה אייקון בשולחן העבודה.
היא עובדת רק כשהחלון השחור של `run.bat` או `run.sh` פתוח ברקע.

## שימוש מהטלפון באותה רשת Wi-Fi

1. ב-Windows מפעילים את `run-lan.bat`. ב-Mac / Linux מריצים `./run.sh --lan`.
2. בחלון השחור מופיעה כתובת כמו `http://192.168.1.20:5000`. פותחים אותה בדפדפן של הטלפון.
3. אם הטלפון לא מתחבר, ייתכן שחומת האש של המחשב חוסמת. צריך לאשר גישה ל-Python.

## איפה נשמרים הנתונים

הכול נשמר בקובץ אחד: `data/kis.sqlite3`.
- כדי לגבות, מעתיקים את התיקייה `data` למקום בטוח. אפשר גם להשתמש ב"גיבוי ושחזור" שבתוך האפליקציה.
- הקובץ `data/secret.key` שומר על החיבורים. אסור לשתף אותו.

## פרטיות

- כל משתמש רואה רק את הנתונים שלו. השרת בודק את זה בכל בקשה.
- הסיסמאות נשמרות מוצפנות (hash), ולא כטקסט.
- שום מידע לא יוצא מהמחשב שלך. גם הגופנים וספריית ה-PDF שמורים מקומית.

## מבנה התיקייה

```
flow/
├── app.py                 השרת: כניסה, הרשמה ושמירת נתונים (Flask + SQLite)
├── requirements.txt       הספריות שצריך
├── run.bat / run-lan.bat  הפעלה ב-Windows
├── run.sh                 הפעלה ב-Mac / Linux
├── templates/login.html   מסך כניסה והרשמה
├── static/
│   ├── index.html         האפליקציה עצמה
│   ├── manifest.webmanifest, sw.js   התקנה כאפליקציה
│   ├── fonts/, fonts.css  גופנים מקומיים
│   ├── vendor/            ספריית PDF
│   └── icons/             אייקונים
└── data/                  נוצר בהפעלה הראשונה, כאן כל הנתונים
```

## לאנשים טכניים

- הפעלה ידנית: `pip install -r requirements.txt`, ואז `python app.py`.
- דגלים: `--lan` (גישה מהרשת המקומית), `--port 8080`.
- ה-API: `GET/PUT/DELETE /api/doc/<name>`, `GET /api/me`, `POST /api/password`. כל הבקשות מוגבלות למשתמש המחובר.
- השרת רץ על waitress כשהיא מותקנת, ואם לא, על שרת הפיתוח של Flask.
